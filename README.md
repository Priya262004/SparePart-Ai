# SparePart AI

An AI-powered spare parts management system for manufacturing.

## Features

* Semantic search for spare parts
* Inventory overview and stock tracking
* Low-stock and out-of-stock alerts
* Restocking quantity recommendations
* Downloadable restocking reports
* Search history

## Technologies Used

* Python
* Streamlit
* Pandas
* Sentence Transformers
* Scikit-learn

## How to Run

1. Install the required packages:

   `pip install -r requirements.txt`

2. Start the application:

   `streamlit run app.py`

## Project Goal

To help manufacturing teams find spare parts, check availability, and plan restocking more easily.
